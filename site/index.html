This week's spreads

Each dot is the predicted final margin. Lines are written like a sportsbook's: the favorite takes the minus sign. Ticks mark 3, 7, 10 and 14, the margins football games land on most often.

Track record

Every published prediction, graded against the final score and the Vegas closing line. Misses are in points.

Game by game

Against the spread, the model takes whichever side of the closing line its prediction falls on. A win means the final margin landed on that side.

How it works

  • Every Tuesday in season, a linear regression is retrained on every game since 1999, using each team's running averages: yards, points, sack yards, EPA.
  • Early-season averages lean on the previous season until real games accumulate.
  • Before publishing, the run checks that the data is complete and current, and that a fixed backtest still reproduces its committed results.
  • Each week's release is never edited after it's published, so this record only contains predictions made before kickoff.
